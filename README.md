# hw_course_4

## Описание:

hw_course_4 - это проект, в котором пишутся домашки 4 курса.

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/RomanBatyuk/hw_course_4
```
2. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование:

1. Откройте проект в PyCharm.
2. Теперь вы можете поучавствовать в учебном процессе ;)
3. Для тестирования функционала обратитесь к директории tests в корне проекта.

## Функционал:

В директории src:

* В модуле classes.py написана домашка по теме 14.1 Введение в ООП, 14.2 Режимы доступа, 15.1 Магические методы,
  16.1 Наследование, 16.2 Множественное наследование, 17.1 Исключения.
